# App khách hàng — Tứ Quý Đường

PWA cho khách của Tứ Quý Đường (`tuquyduong.com`): menu, điểm, voucher, hạng, lịch sử đơn — đọc qua cổng `/api/kh` của POS.
Không giữ tiền / điểm / giá / khách: mọi thứ đó ở POS.

- Luật làm việc: `CLAUDE.md`, `LUAT_XAY_APP.md`
- Thiết kế: `thiet_ke/` (demo, đặc tả, hợp đồng `/api/kh`)
- Sổ việc: `TIEN_DO_APPKH.json`
- Bộ khung tự chạy: `tu_chay/` (chép nguyên từ POS, bản 1.8.0)
